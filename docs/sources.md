# Поддерживаемые источники

Ссылку можно прислать в боте вместе с любым текстом — бот сам её найдёт.

## 1. Habr.com

**Тип контента:** технические статьи.

**Формат URL:** `https://habr.com/ru/articles/[ID]/` (также `/news/` и `/post/`).

**Что извлекается:**
- Заголовок, автор, дата публикации
- Текст статьи (до 60 000 символов)
- Комментарии — отдельным запросом к JSON API, который использует сам сайт. Берутся только опубликованные комментарии, с автором, рейтингом, пометкой «автор статьи» и ссылкой на комментарий, на который отвечают

Если комментарии загрузить не удалось, статья всё равно разбирается — просто без них.

## 2. GitHub.com

**Тип контента:** документация репозитория.

**Формат URL:** `https://github.com/[owner]/[repo]`

**Что извлекается:**
- Название, владелец, описание
- Звёзды, основной язык, лицензия, дата последнего push, признак «в архиве» (последние три — только через GitHub API; без него в конспекте будет «нет данных»)
- README.md и другие файлы документации из корня и папки `docs/`: ARCHITECTURE, CONTRIBUTING, DEVELOPMENT, SETUP, INSTALL, USAGE, API, CHANGELOG

**Особенности:**
- Содержимое файлов объединяется, предел — 120 000 символов
- Без `GITHUB_TOKEN` GitHub API даёт 60 запросов в час, с токеном — 5000
- Конспект — справка из трёх абзацев: назначение, технологии, зрелость проекта

## 3. InfoStart.ru

**Тип контента:** статьи и публикации по 1С.

**Форматы URL:**
- `https://infostart.ru/1c/articles/[ID]/`
- `https://infostart.ru/public/[ID]/`

**Что извлекается:**
- Заголовок
- Автор (имя и логин из карточки автора)
- Теги публикации
- Текст статьи (до 60 000 символов) без кнопок, галереи скриншотов, вкладки файлов и рекламных блоков
- Комментарии с той же страницы: автор, номер, ссылка на комментарий, на который отвечают, пометка «автор статьи». Рейтинга у комментариев Инфостарта в HTML нет

**Особенности:**
- Сайт показывает проверку на бота: короткий скрипт ставит cookie и перезагружает страницу. Парсер проходит её сам, повторив запрос с этой cookie. Если формат проверки изменится, бот ответит «Сайт не пропустил проверку на бота»
- Страницы в кодировке cp1251 — парсер определяет её автоматически

## Комментарии в конспекте

Для Хабра и Инфостарта комментарии передаются модели вместе со статьёй (примерно до 12 000 символов): сначала ответы автора статьи, потом самые высоко оценённые, комментарии с отрицательным рейтингом отбрасываются. Если в обсуждении есть поправки, критика, альтернативы или опыт — конспект заканчивается коротким абзацем «В комментариях:». Если там только благодарности — абзаца не будет.

Комментарии в базе не сохраняются.
